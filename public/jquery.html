jQuery

YuktAI on jQuery sites

jQuery still runs on most websites: WordPress themes, ASP.NET WebForms, PHP and older business sites. YuktAI and Ask page are plain JavaScript and don't depend on jQuery, so they work next to any jQuery version. Two script tags, no plugin, no changes to your jQuery code.

  • Tested with jQuery 1.12.4, 2.2.4, 3.7.1 and 4.0.0: data grid, accessibility settings and Ask page, no console errors.
  • No jQuery plugin to install or update. YuktAI doesn't need jQuery at all.
  • No API keys, no server calls. Everything runs in the visitor's browser.

Try it with any jQuery version

Loading jQuery…

The buttons and the grid are wired with jQuery ($(function () { … }), $("#id").on("click")). Full example: examples/jquery on GitHub (opens in a new tab)

1. Add the scripts

Put these just before </body>, after the jQuery you already have.

index.html (before </body>)
<!-- 1. jQuery: pin the version (4.0 for new sites, 3.7 for old code) -->
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>

<!-- 2. YuktAI: ♿ accessibility widget, page tools, data grid -->
<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/yuktai@5.3.12/vanilla/index.min.js"></script>

<!-- 3. Ask page: answers from this page, sources highlighted -->
<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/ask-page@1.0.0/dist/ask-page.global.js" defer></script>

That's all. The ♿ button and the Ask panel appear on every page.

2. Call YuktAI from jQuery code

window.yuktai and the <yuktai-ask> element are ordinary JavaScript, so you call them from $(function () { … }) like any other code.

your-page.js
$(function () {
  // Data grid: pass a jQuery element with [0], or a CSS selector
  yuktai.renderGrid($("#staff")[0], { data: rows, columns: cols, engine: "auto" })

  // Accessibility from your own button
  $("#contrastBtn").on("click", function () {
    yuktai.apply({ highContrast: true })
  })

  // Open Ask page with a question
  $("#helpBtn").on("click", function () {
    document.querySelector("yuktai-ask").askQuestion("How do I apply?")
  })
})

YuktAI and Ask page work with every jQuery we tested: 1.12.4, 2.2.4, 3.7.1 and 4.0.0. Use 4.0 for new sites and 3.7 for older code.

4. Use the latest version, safely

Pin the version

Load jquery-4.0.0.min.js, not a "latest" link. You decide when to upgrade, after testing.

Avoid jquery-latest.js

Despite its name, jQuery stopped updating that file years ago. It still serves an old 1.x release.

Don't auto-follow major versions

jQuery 4 removed old APIs such as $.trim, $.isArray, $.parseJSON and $.now. An automatic jump from 3 to 4 can break older page code.

New sites: 4.0 · Old sites: 3.7

Start new work on 4.0. Keep older sites on 3.7 until you have tested them with jQuery Migrate.

5. Upgrading an old site to jQuery 4

Add jQuery Migrate for a while. It keeps most old code working and logs a warning for each API that changed, so you can fix them one by one.

Upgrade check
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
<!-- shows a console warning for each old API your code still uses -->
<script src="https://code.jquery.com/jquery-migrate-4.0.2.min.js"></script>
Common replacements in jQuery 4
Old (removed)Use instead
$.trim(s)s.trim()
$.isArray(a)Array.isArray(a)
$.parseJSON(t)JSON.parse(t)
$.now()Date.now()
$.isFunction(f)typeof f === "function"

6. Where to put it

WordPress

Add the YuktAI scripts in the theme footer, or use the PHP package with wp_footer. WordPress already loads jQuery.

ASP.NET WebForms

Add the scripts once in Site.Master, before </body>. Every page that uses the master gets them.

Site.Master
<%-- Site.Master, just before </body> --%>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/yuktai@5.3.12/vanilla/index.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/ask-page@1.0.0/dist/ask-page.global.js" defer></script>

7. Sites with a strict security policy

jQuery 4 supports Trusted Types, and so does Ask page: both work with require-trusted-types-for 'script'. If your site has a Content Security Policy, allow cdn.jsdelivr.net and code.jquery.com in script-src, plus 'wasm-unsafe-eval' for the Rust engines. Without it, YuktAI still works, using its TypeScript search.
