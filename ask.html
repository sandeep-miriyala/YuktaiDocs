Ask page (RAG)

Ask page (RAG)

Answer questions from your own text, your page and your grid data. YuktAI finds the best passages and quotes them; an optional on-device model can then write the answer from only those passages.

What it is, honestly: the built-in search below (createContextIndex) is BM25 keyword retrieval with prefix matching and Telugu-aware tokens, in TypeScript or Rust. It finds passages that share words with the question. For meaning search (embeddings), use the new Ask page panel in Balanced mode.

New: the Ask page panel @yuktishaalaa/ask-page 0.1.0

A side panel that answers questions about the page from the page itself, highlights where each answer came from, and says so when the page does not answer it. It is running on this site now: press Ask in the top bar, or Ctrl + /.

Live on these docs

Open the panel and try one of these. Every answer shows its source; click it to see the passage highlighted on this page.

Also on its own page: the Ask page demo (opens in a new tab), with a Telugu section and a form to test the privacy filter.

Modes

Ask page modes
ModeSearchAnswerDownload
FastRust BM25 (WebAssembly, 52 KB)The best sentences from the page, quotedAbout 100 KB, nothing else
BalancedKeywords plus meaning (multilingual embeddings), merged with RRFChrome built-in AI if it is ready, else quotedAbout 118 MB once, after the visitor agrees
BestSame as BalancedChrome built-in AI, or WebLLM if the site enables itMore, once

Privacy and accessibility

  • Never reads what visitors type: input and textarea values, passwords, rich-text editors and anything marked data-ask-private are skipped before the page is indexed.
  • Page text and questions stay on the device. No server, no API key, no analytics on questions, no tracing. On pages that look signed-in, nothing is saved.
  • Says "This page doesn't answer that" instead of guessing, and labels AI answers with "AI can be wrong. Check the source."
  • 17 px text (18 px for Telugu) with A− / A+, 44 px buttons, keyboard and screen reader support, dark and light, high contrast. axe: 0 violations.
  • Browser agents can use it through read-only WebMCP tools: ask_page, get_page_outline, get_suggested_questions.

Add it to your site

app/AskPage.tsx
"use client"
// app/AskPage.tsx: add once, in app/layout.tsx
import { useEffect } from "react"
import { mountAskPage } from "@yuktishaalaa/ask-page"

export default function AskPage() {
  useEffect(() => {
    mountAskPage({
      modes: ["fast", "balanced"],   // what visitors may pick
      questions: [{ text: "How do I apply?", path: "/scheme" }],
    })
  }, [])
  return null
}

app/help/AskHelp.tsx
"use client"
import { useMemo, useState } from "react"
import { createContextIndex } from "@yuktishaalaa/yuktai"

const documents = [
  { id: "leave", text: "Leave policy: every employee gets 24 days of paid leave a year." },
  { id: "wfh", text: "Work from home: staff may work from home two days a week." },
]

export function AskHelp() {
  // includePage: true also indexes the visible page text
  const index = useMemo(() => createContextIndex({ documents, includePage: false, engine: "rust" }), [])
  const [answer, setAnswer] = useState("")
  async function onAsk(question: string) {
    const r = await index.ask(question, { k: 4 })   // { answer, hits: [{ id, text, score }], generated }
    setAnswer(r.answer)
  }
  return (/* your input + <p aria-live="polite">{answer}</p> */ null)
}
help.html
<script>
  const index = yuktai.createContextIndex({
    documents: [
      { id: "leave", text: "Leave policy: every employee gets 24 days of paid leave a year." },
      { id: "wfh", text: "Work from home: staff may work from home two days a week." }
    ],
    includePage: false,      // true: also index the visible page text
    // rows, columns, rowKey: also index grid data
    engine: "rust"           // "ts" | "rust" | "auto"
  })

  const r = await index.ask("How many leave days do I get?", { k: 4 })
  r.answer   // quoted from the best passages, nothing invented
  r.hits     // [{ id, source, text, score }]
  index.search("leave days", 3)   // ranked passages only
</script>


Let a model write the answer (optional)


Pass generate to ask. YuktAI sends the model only the question and the top passages, so the answer stays grounded. Chrome's built-in Gemini Nano runs on the device; any API works too.


lib/generate.ts
// Chrome built-in AI (Gemini Nano). Falls back to the quoted answer when it is not available.
export async function generate(question: string, context: string) {
  const LM = (globalThis as any).LanguageModel
  if (!LM) throw new Error("No on-device model")
  const session = await LM.create()
  return session.prompt(
    "Answer only from these passages. If they do not answer it, say so.\n\n" + context + "\n\nQuestion: " + question
  )
}

// const r = await index.ask(question, { generate })   → r.generated === true
app.js
async function generate(question, context) {
  if (!window.LanguageModel) throw new Error("No on-device model")
  const session = await LanguageModel.create()
  return session.prompt("Answer only from these passages.\n\n" + context + "\n\nQuestion: " + question)
}
